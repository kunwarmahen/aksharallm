Tools — a 300M model that knows when to call Python

A small model cannot multiply five-digit numbers in its head, count the letters in a word, or work out the days between two dates. It can learn to write the line of Python that does, read what it printed, and answer. The tool's output is never trained on, only the call and the answer, so the model learns to use the tool rather than to guess what the tool will say. Read chapter 6, "Tool use".

question → the model writes<tool>print(…)</tool> → sandbox runs itinfer/sandbox.py → the model answers

Is it right?

140 problems the model never saw, 20 of each kind, with the tool and without. The held-out kind was never in training: it is the column that says whether the model learned "use a tool for arithmetic" or only six templates.
