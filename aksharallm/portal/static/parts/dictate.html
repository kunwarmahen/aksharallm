Dictation — speech in, text out, and still right on day two

A from-scratch speech recogniser: it turns 10 ms slices of sound into a picture (log-mel), a Conformer reads that picture, and every 40 ms it guesses one letter — or blank, meaning "nothing new here". Read the chapter.

microphone48,000 samples/s → log-mel80 bands, 100/s → Conformerattention + convolution → a letter or blank25 times a second → merge repeats,
drop blanks
No recogniser yet. The smoke run needs no download and takes a few minutes: 
.venv/bin/python -m aksharallm.audio corpus --out data/audio/synth-asr --clips 400
scripts/audio.sh asr-synth
It only knows five vowel names. For one that knows English, train on LibriSpeech: 
.venv/bin/python -m aksharallm.asr fetch train-clean-100 && .venv/bin/python -m aksharallm.asr pack train-clean-100
scripts/audio.sh asr-libri100

The day-two checks

A weekend clone works on day one. These are the five ways it stops working once someone actually uses it — each one a measurement here, not a promise.

1it writes words nobody said ("thank you for watching") characters written on five clips with no speech — must be 0
2accentsWER per speaker, worst beside the median see the table below
3switching language mid-sentenceWER on a mixed-language set not built yet
4names (Shaun or Sean?)words the LM has never seen, recalled with and without a personal dictionary — and how often one is written where nobody said it run asr eval --decoder beam
5never learns from a correctionright on the 4th try after 3 corrections? not built yet
