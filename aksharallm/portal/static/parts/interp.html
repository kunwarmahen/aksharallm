what each layer believed, what attention attended to, and which activation actually carries the answer

Logit lens

every block adds to the residual stream, so the output head can be pointed at the running total halfway through: not what the model predicted, but when it decided

A reading, not a measurement: nothing says an intermediate residual is supposed to decode to anything. Treat a clean story as a hypothesis and check it with Patching, which intervenes rather than observes.

Attention

recomputed from the layer's own inputs — the fused kernel never stores these

Read a row: it is what that position looked at, and it sums to 1. Everything above the diagonal is empty because a token cannot attend to its future.

Activation patching

run the corrupted prompt, force one activation back to its clean value, and see whether the answer returns

The two prompts must tokenize to the same length, or position 7 means different things in the two runs and every cell compares unrelated activations. Green is "patching this alone restores the clean answer".

Dictionary features

a sparse autoencoder over the residual stream: 8x wider, almost all zeros, so features stop overlapping

Training one is a terminal job — it reads a corpus: python -m aksharallm.interp sae <run> --layer 12. What a feature means needs the tokens it fires on: python -m aksharallm.interp features <run> --feature N.
