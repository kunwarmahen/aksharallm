Temperature 0 is greedy — the setting to use when comparing two checkpoints, since it removes the sampling luck. A fixed seed does the same for temperature above 0. draft turns on speculative decoding with no draft model: the next tokens are guessed by looking up where the last few occurred before, and the big model checks them all in one pass. The text is identical either way — the status line says how many guesses it accepted.
