World model — the transformer predicting what a game does next

A language model predicts the next word. A world model predicts the next state of a world, given what just happened and what someone did. This one learns a box-pushing game we wrote, so every prediction can be checked exactly. Each 8×8 frame is 64 tokens; the action is one more. The trainer is the ordinary pretraining loop. Read chapter 25.

frame64 cells + actionup · down · left · right · stay → transformer13.8M, unchanged → next frame64 cells

How good is it?

Exact means all 64 cells of the next frame right. Read every number against copy: a model that just repeats the last frame is perfect when the agent bumps a wall and useless when anything moves, and averages to about a third. The rollout feeds the model its own frames back; an impossible frame (two agents, a hole in the wall) is the world-model version of a hallucination.

The keys world is harder on purpose. A move slips sideways one time in ten, so there is no single right next frame, only the right probabilities: KL is how far the model's are from the game's (0 is perfect). And a key vanishes when picked up and is never drawn again, so whether the next door opens depends on something the picture does not show. The door table asks how sure the model is that the door opens, split by whether the pickup happened inside what it can read, before that, or never.
